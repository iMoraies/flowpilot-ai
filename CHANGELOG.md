# Changelog

## 0.1.0

- Added project foundation with Fastify, TypeScript, Prisma, PostgreSQL, Redis, Docker, Vitest, and OpenAPI.
- Added authentication with JWT access tokens and refresh token rotation.
- Added RBAC and organization-level multi-tenancy.
- Added workflow definitions, activation validation, and snapshot versioning.
- Added asynchronous workflow execution with BullMQ and worker processing.
- Added AI classification through a provider abstraction with a mock provider.
- Added safe HTTP request step, condition branching, task creation, notification logging, audit logs, metrics, tracing base, seed data, and demo script.
